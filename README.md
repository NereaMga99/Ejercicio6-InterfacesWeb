# Mina de Historias: Tu Biblioteca Personal y Tienda de libros de segunda mano.
Mina de Historias es una plataforma diseñada para los amantes de la lectura. Combina la funcionalidad de una biblioteca personal digital con una tienda de segunda mano, facilitando a los usuarios el seguimiento de sus hábitos lectores y el intercambio de libros de forma sencilla y sostenible.
La finalidad del proyecto es doble: promover la lectura mediante el mercado de segunda mano y ayudar a los usuarios a organizar sus lecturas diarias de manera visual y práctica.

## Funcionalidades Principales
### Biblioteca Personal
- Registro de lecturas: Sube tus libros con foto, descripción y la fecha en la que los terminaste.
- Reseñas personales: Escribe qué te ha parecido cada libro para recordarlo en el futuro.
- Organización temática: Tanto la biblioteca como la tienda están categorizadas por géneros para facilitar la navegación.

### Tienda de Segunda Mano
- Venta fácil: Publica libros que ya no uses simplemente indicando el precio y subiendo una foto.

### Perfil de Usuario y Estadísticas
- Panel de control: Resumen total de libros leídos y acceso rápido a las 3 últimas lecturas añadidas.
- Gestión de ventas: Resumen de libros disponibles para vender y registro del último libro vendido.
- Gráfica de actividad: Visualización de la actividad lectora de los últimos 6 meses para motivar el hábito de lectura.

## Tecnologías y Mejoras Técnicas
Este proyecto no solo se enfoca en la experiencia del usuario, sino también en la calidad técnica:
- Optimización Lighthouse: Puntuaciones altas en Rendimiento, Accesibilidad y SEO.
- Rendimiento: Uso de imágenes en formato WebP, minificación de archivos CSS y precarga de fuentes locales para una carga instantánea.
- Accesibilidad (WCAG AA): Contraste de colores optimizado, etiquetas semánticas corregidas y áreas de clic (tap targets) ampliadas para dispositivos móviles.
- Privacidad: Eliminación de cookies de terceros mediante el auto-alojamiento de fuentes e iconos.
